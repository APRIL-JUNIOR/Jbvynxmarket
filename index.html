SISTEM DIRECT

Sistem Direct adalah metode transaksi langsung melalui admin VYNX STORE dengan alur yang sederhana, jelas, dan teratur agar proses transaksi lebih mudah dipahami oleh buyer dan admin.
01 — Buyer Transfer

Buyer Transfer

Buyer melakukan transfer pembayaran kepada admin.

02 — Admin Cek Transfer

Admin Cek Transfer

Admin memeriksa dan memastikan pembayaran buyer sudah masuk.

03 — Admin Memberikan Barang

Admin Memberikan Barang

Setelah pembayaran terkonfirmasi, admin memberikan barang kepada buyer.

04 — Buyer Mengamankan Barang

Buyer Mengamankan Barang

Buyer menerima dan mengamankan barang yang telah diberikan admin.

05 — Admin Menunggu Konfirmasi

Admin Menunggu Konfirmasi

Admin menunggu buyer memastikan bahwa barang sudah diamankan.

06 — Buyer Mengatakan DONE

Buyer Mengatakan DONE

Buyer memberikan konfirmasi bahwa transaksi sudah selesai dari sisi buyer.

07 — Transaksi Selesai

Transaksi Selesai

Transaksi dinyatakan selesai.

SISTEM SISP

Sistem SISP adalah metode transaksi dengan admin sebagai pihak yang mengamankan barang selama proses transaksi berlangsung, sehingga setiap tahap dapat dilakukan secara terstruktur sampai transaksi selesai.
01 — Seller Memberikan Barang

Seller Memberikan Barang

Seller memberikan barang kepada admin.

02 — Admin Mengamankan Barang

Admin Mengamankan Barang

Admin menerima dan mengamankan barang dari seller.

03 — Seller Menunggu Konfirmasi

Seller Menunggu Konfirmasi

Seller menunggu sampai admin memastikan barang sudah diamankan.

04 — Admin Meminta Payment Seller

Admin Meminta Payment Seller

Admin meminta metode pembayaran seller, seperti nomor rekening atau QRIS.

05 — Seller Mengecek Transfer

Seller Mengecek Transfer

Seller memeriksa pembayaran yang dikirim oleh admin.

06 — Admin & Seller Menyelesaikan Transaksi

Admin & Seller Menyelesaikan Transaksi

Admin dan seller melakukan konfirmasi akhir.

07 — Transaksi Selesai

Transaksi Selesai

Transaksi dinyatakan selesai.
